# Getting help

- **Questions and ideas:** [Discussions](../../discussions).
- **Bugs:** [open an issue](../../issues/new/choose) with steps to reproduce, browser, and hosted or self-hosted mode.
- **Security problems:** [SECURITY.md](SECURITY.md), privately.

Supported: the latest release, in both usage modes (see the [README](README.md)). Before you report a data problem in self-hosted mode, back up the data directory (the Docker volume); in hosted mode, export your drawings as `.yodo` files.
